Personal learning project — portfolio piece

NBA Fantasy

A full-stack fantasy basketball app: run a live draft with your friends, trade players, manage rosters across leagues and talk trash in the league chat — all updating in real time.

Built end to end by one developer to practise production patterns: Angular 21 on the front, a .NET API behind it, and WebSockets in between.

Use Login or Sign Up in the top-right corner to try it yourself.

This is a learning project, not a commercial product

I built WebNBAFantasy to teach myself how a real-time, multi-user web app is put together — and to have something concrete to show employers. There are no ads, no payments and no data selling. It is not affiliated with, endorsed by or sponsored by the NBA; player and team names appear for educational purposes only.
